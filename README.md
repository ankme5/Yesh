# Yash & Komal – wedding invitation (26.12.2026)

Single-page digital invite. Open `index.html`, or deploy the folder to GitHub Pages (`https://ankme5.github.io/Yash-Badge-2612/`).

- `music.mp3` (optional): drop a track here to replace the generated singing-bowl music.
- `img/logo-dark.png`: the Y & K logo (transparent). `img/buddha.png` and `img/ambedkar.png` (optional line-art) appear gold-tinted on the hero.
- `thumbnail.jpg`: WhatsApp/OG preview (1200x630), rendered from `og.html`.
- Text and translations live in the `T` object in `index.html` (`hi` / `en`). Add `?lang=en` to a link to open in English.
